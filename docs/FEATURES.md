# 功能详细说明

本文档逐项介绍「汽车百科」小程序的全部功能模块。

---

## 一、启动与首页

### 1.1 启动页（splash）

- 展示品牌名 **「汽车百科」** 与 Slogan「零部件 · 故障 · 一站查询」
- 约 2 秒后自动跳转首页
- 自定义导航栏，沉浸式深色背景

### 1.2 首页（index）

首页是小程序的 **核心枢纽**，自上而下共 **10 大区块**，支持下拉刷新。导航栏标题为「首页」，白色清爽主题（`#f7f8fa` 背景）。

#### 区块总览（自上而下）

| 序号 | 区块 | 显示条件 | 数据来源 | 点击行为 |
|------|------|----------|----------|----------|
| ① | 保养到期横幅 | 有过期或今日到期项 | 本地 `car_maintain` | 跳转「保养提醒」 |
| ② | 综合搜索栏 | 始终 | — | 跳转「综合搜索」 |
| ③ | 热门关键词 | API 返回热词时 | `/api/home/recommendations` | 带关键词跳转综合搜索 |
| ④ | 快捷入口（4 个） | 始终 | `home-config.js` | 见下表 |
| ⑤ | 数据概览 | API 加载成功 | parts + faults + categories 接口 | 仅展示，不可点 |
| ⑥ | 今日推荐 | 推荐 API 成功 | `/api/home/recommendations` | 零件→详情 / 故障→详情 |
| ⑦ | 最近浏览 | 本地有历史时 | `car_history`（最多 5 条） | 跳转详情；「全部」→浏览历史 |
| ⑧ | 核心功能（2 卡片） | 始终 | — | 零件科普 / 故障分析 |
| ⑨ | 常用工具（12 宫格） | 始终 | `home-config.js` | 见下表；「全部」→快捷菜单 |
| ⑩ | 推荐服务（4 卡片横滑） | 始终 | `home-config.js` | 跳转对应养车指南 |

#### ① 保养到期横幅

- **红色样式**：存在已过期保养项，标题「保养已过期」
- **橙色样式**：仅今日到期，标题「保养今日到期」
- 展示最多 2 项名称，超出显示「等 N 项」
- 进入首页时若有过期/今日项，**每日首次** Toast 提示（`maintain_tip_日期`）
- 7 日内到期仅在保养页高亮，**不在首页出横幅**

#### ② 综合搜索栏

- 圆角白底搜索框，占位符「搜索零部件、故障关键词…」
- 点击进入 **综合搜索页**，可同时检索 106 零件 + 24 故障

#### ③ 热门关键词

- 默认热词：`火花塞、刹车片、发动机抖动、烧机油、ABS、空调不制冷、蓄电池、正时皮带`（API 下发）
- 点击 chip 直达综合搜索并 **自动执行搜索**

#### ④ 快捷入口（一行 4 个）

| 图标 | 名称 | 跳转页面 |
|------|------|----------|
| 🤖 | 问小汽 | AI 聊天（小汽） |
| 🔍 | 综合搜索 | 统一搜索 |
| 🩺 | 症状诊断 | 多症状匹配故障 |
| 📷 | 扫码识件 | 扫码/输入查零件 |

#### ⑤ 数据概览

- 三列统计：**零部件数**（黑） / **故障案例数**（红） / **系统分类数**（蓝）
- 数字来自后端实时统计（106 / 24 / 11）
- 加载中显示骨架屏

#### ⑥ 今日推荐

- 横向滚动卡片
- **4 个随机零件**：缩略图 + 名称，来自 API `ORDER BY RANDOM()`
- **3 个随机故障**：标题 + 分类名
- 每次下拉刷新或重新进入会更新推荐

#### ⑦ 最近浏览

- 展示本地最近 **5 条** 浏览记录（零件显示缩略图，故障显示 🔧 图标）
- 右侧「全部」进入 **浏览历史** 页（完整列表、分类筛选、删除）

#### ⑧ 核心功能（两大模块卡片）

| 卡片 | 说明 | 跳转 |
|------|------|------|
| 汽车零部件科普 | 11 大系统 · 高清图解 · 故障表现 | 零件分类页 |
| 汽车故障分析 | 现象 · 原因 · 方案 · 危险等级 | 故障分类页 |

#### ⑨ 常用工具（4×3 宫格，共 12 项）

| 工具 | 副标题 | 角标 | 跳转 |
|------|--------|------|------|
| 保养提醒 | 到期提醒 | HOT | 保养提醒 |

| 我的爱车 | 车辆档案 | — | 我的爱车 |
| 油液对照 | 型号查询 | — | 油液对照 |
| 胎压参考 | 标准值 | — | 胎压参考 |
| 油耗记录 | 行车账本 | — | 油耗记录 |
| 浏览历史 | 最近查看 | — | 浏览历史 |

#### ⑩ 推荐服务（横向滚动 4 卡片）

| 服务 | 描述 | 标签 | 跳转指南 |
|------|------|------|----------|
| 新手养车指南 | 从保养到故障自查 | 入门 | beginner |
| 维修知识课堂 | 图文+案例学习 | 学习 | classroom |
| 年检自查清单 | 上线前自检项目 | 实用 | inspection |

#### 首页交互与刷新

| 操作 | 行为 |
|------|------|
| 下拉刷新 | 重新拉取统计数据、今日推荐、热门词 |
| 每次 onShow | 刷新最近浏览、检查保养横幅 |
| onLoad | 首次加载全部 API 数据 |

#### 首页数据流示意

```
首页 index
├── API: GET /api/parts          → 零件总数
├── API: GET /api/faults         → 故障总数
├── API: GET /api/parts/categories → 分类数
├── API: GET /api/home/recommendations → 推荐 + 热词
└── 本地: car_maintain / car_history → 横幅 + 最近浏览
```

## 二、零部件科普

### 2.1 分类浏览

11 大系统：发动机、燃油、排气、冷却润滑、传动、制动、转向、底盘悬架、电气、空调、安全。

### 2.2 零件列表

按分类展示该类别下全部零件，点击进入详情。

### 2.3 零件详情

- 高清 PNG 配图（106 张，后端静态资源）
- 名称、所属系统
- **作用**、**安装位置**、**故障表现**
- **收藏**按钮（本地 storage）
- **相关故障**列表（API 按名称匹配）
- **分享给好友**（微信分享卡片）

### 2.4 零件搜索

独立搜索页，支持 URL 参数 `?keyword=` 预填并自动搜索。

---

## 三、故障分析

### 3.1 分类浏览

六大类：发动机故障、刹车故障、异响、漏油、启动困难、电器故障。

### 3.2 故障详情

- 标题、分类、**危险等级**（低/中/高/极高，颜色区分）
- **故障现象**、**可能原因**（列表）
- **涉及零件**（点击跳转综合搜索）
- **解决方法**（步骤列表）
- 收藏、分享

### 3.3 故障搜索

关键词搜索标题、现象、原因。

## 四、综合搜索

- Tab：**全部 / 零件 / 故障**
- 一次请求 `/api/search`，结果分区展示
- 热门搜索词（首页同步）
- 零件结果带缩略图
